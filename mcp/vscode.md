# VS Code

Open the Command Palette, select **MCP: Add Server**, choose **HTTP**, and use:

```text
https://mcp.omnidim.io/mcp
```

Sign in when VS Code requests authorization, then ask your coding agent to list
your OmniDimension agents.

See the [full VS Code guide](https://docs.omnidim.io/docs/mcp/connect/vscode).
