# OmniDimension MCP

Connect an AI coding client to OmniDimension through the hosted OAuth server.
Each setup uses `https://mcp.omnidim.io/mcp` and authenticates in the browser on
first use.

Part of [OmniDimension examples](https://github.com/Omnidim/examples).

## Client setup

- [Claude Code](./claude-code.md)
- [Codex](./codex.md)
- [Cursor](./cursor.md)
- [VS Code](./vscode.md)

## Prompt recipes

Use the recipes in [prompts.md](./prompts.md) after connecting. They are bounded
operational tasks that help you inspect an account, provision an agent, and
review calls without publishing credentials in the repository.

For the full product guide, see the [MCP documentation](https://docs.omnidim.io/docs/mcp)
and [Connect OmniDimension to Claude](https://www.youtube.com/watch?v=5dh4SumJgZw).
