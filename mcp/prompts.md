# Prompt recipes

## Inspect an account

```text
List my OmniDimension agents and summarize each agent's purpose, phone number, and recent call volume. Do not change anything.
```

## Prepare an agent

```text
Create a draft appointment-booking voice agent. Give it a concise welcome message and a clear fallback for requests it cannot complete. Do not deploy it or dispatch calls.
```

## Audit recent calls

```text
Review my ten most recent completed calls. Identify recurring unanswered questions and propose three prompt improvements. Do not edit the agent.
```

## Start a controlled campaign

```text
Before creating anything, show me the agent, phone number, contact count, schedule, and retry settings you would use for a five-contact test campaign. Wait for my approval before creating it.
```
