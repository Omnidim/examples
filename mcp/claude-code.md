# Claude Code

```bash
claude mcp add --transport http omnidim https://mcp.omnidim.io/mcp --scope user
```

Claude Code opens the OmniDimension consent screen when you first use the
connector. Verify the connection by asking: `What OmniDimension agents do I have?`

See the [full Claude Code guide](https://docs.omnidim.io/docs/mcp/connect/claude-code).
